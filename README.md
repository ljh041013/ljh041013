## Projects

### 01. 치지직 잼포인트 · CHZZK JamPoint

**긴 다시보기에서 채팅 반응이 몰린 장면을 찾아가는 도구.**

다시보기를 처음부터 훑는 대신, 시청자의 채팅 반응을 영상 위에서 확인할 수 있도록 만든 Chrome 확장프로그램입니다. 전체 채팅을 분석해 재생 바 위에 그래프를 표시하고, 관심 구간으로 바로 이동할 수 있게 했습니다.

- **반응 시각화:** 시간대별 채팅과 웃음·물음표 반응을 그래프로 표시
- **탐색 조절:** 지표, 가중치, 임계값을 바꿔 원하는 구간을 선택
- **구간 이동:** 이전·다음 장면 탐색과 이동 시점 조절
- **결과 활용:** 시간·전체 타임라인 복사와 CSV 내보내기

반응 분석 결과를 그래프, 구간 목록, 실제 영상 탐색으로 연결했습니다.

`JavaScript` `Chrome Extension` `채팅 데이터 분석`

### 02. RiotWatcher

**친구의 게임 상태를 한 화면에서 확인하는 데스크톱 대시보드.**

Riot 클라이언트의 로컬 API를 이용하는 오픈소스 도구를 바탕으로, 상태 확인과 알림을 데스크톱 화면에 연결했습니다. 조회 결과를 계속 갱신하면서도 화면이 멈추지 않도록 네트워크 작업과 UI 갱신을 분리했습니다.

- **상태 표시:** 친구의 온라인 상태, 게임 단계, 맵과 파티 정보 확인
- **데스크톱 화면:** Tkinter 대시보드와 게임 상세 정보 표시
- **변경 알림:** 활동 상태 변화를 감지하고 알림 연결
- **조회 최적화:** HTTP 연결 재사용, 갱신 간격 조절, 성능 측정

반복 조회의 응답성과 화면 갱신 비용을 함께 확인하며 구현했습니다.

`Python` `Tkinter` `로컬 클라이언트 API` `HTTP`

<sub>[ch4rlesexe/RiotWatcher](https://github.com/ch4rlesexe/RiotWatcher)를 기반으로 확장한 프로젝트입니다.</sub>

### 03. Apex Race Radio

**레이스 데이터를 운전 중에 들을 수 있는 정보로 바꾸는 도구.**

게임의 UDP 텔레메트리를 읽어 레이스 상황을 음성과 자막으로 전달하는 Windows용 라디오 도구입니다. 실시간 데이터 해석부터 오버레이, 영어·한국어 음성, 선택적으로 사용하는 로컬 음성 질문까지 하나의 앱으로 구성했습니다.

- **실시간 입력:** 게임 텔레메트리 수신과 패킷 해석
- **상황 전달:** 팀 라디오 오버레이, 영어·한국어 음성 및 자막
- **로컬 처리:** 오프라인 음성 인식·합성과 선택형 PTT 질문
- **상태 관리:** 별도 동의를 통한 레이스 기억, 설정 저장, 진단 기록

실시간 입력을 사용자에게 전달하는 과정과 로컬 실행 환경을 함께 다뤘습니다.

`Python` `UDP` `오프라인 음성 인식·합성` `Windows`

<sub>F1 25 관련 비공식 프로젝트이며, 개발 후보 버전입니다.</sub>

### 04. TrueDepth Selfie Rectification

**원본 사진과 깊이 정보를 활용한 셀카 원근감 보정 연구.**

가까운 거리에서 촬영한 셀카의 원근감을 다루는 카메라 앱 연구입니다. 원본 사진과 깊이 정보를 기반으로 보정 경로를 구현하고, 촬영부터 결과 비교까지의 사용 흐름을 구성했습니다.

- **카메라 흐름:** 실시간 얼굴 분석, 촬영, 사진 가져오기
- **보정 처리:** 깊이 정보와 기하 변환을 활용한 원근감 보정
- **기기 내 모델:** Core ML 기반 모델 리소스와 처리 경로 통합
- **원본 보존:** 원본과 보정 결과를 구분하고 진단·검증 자료를 기록

영상 처리 알고리즘과 앱의 사용 흐름을 함께 설계하면서, 구현된 기능과 실기기 검증 결과를 구분해 기록했습니다.

`Swift` `Vision` `Core ML` `Metal` `Python`

<sub>개발·연구 단계입니다. Apple SDK 빌드와 실제 기기의 속도·화질 검증은 아직 완료되지 않았습니다.</sub>

### 05. Instagram Mutual Map

**팔로워 관계를 목록에서 연결 그래프로 바꾸는 웹앱.**

여러 계정의 팔로워·팔로우 관계를 한눈에 살펴보기 위해 만든 정적 웹앱입니다. 직접 입력하거나 가져온 데이터를 그래프로 표현하고, 관계를 추가·숨김·삭제하면서 탐색할 수 있도록 구성했습니다.

- **데이터 입력:** 계정별 관계 목록과 Instagram 데이터 내보내기 ZIP·JSON 가져오기
- **관계 탐색:** 계정 사이의 연결을 그래프로 확인
- **편집 흐름:** 관계 추가·삭제와 노드 표시·숨김
- **작업 보관:** localStorage 자동 저장, 이름별 저장 슬롯, JSON 내보내기

서버 없이 브라우저에서 데이터를 관리하고, 관계를 탐색하는 인터페이스를 구현했습니다.

`JavaScript` `HTML` `CSS` `localStorage`

### 06. AI Crafting Guide

**아이디어에서 부품 선택, 배선, 펌웨어, 실물 테스트까지.**

하드웨어 아이디어를 떠올려도 어떤 부품을 쓰고 어떻게 연결할지 결정하기는 어렵습니다. 보유한 키트를 기준으로 제작안을 만들고, 학생과 강사가 실제 제작 과정을 함께 진행할 수 있는 웹 도구를 구현했습니다.

- **제작안 생성:** 아이디어와 후속 요청을 부품 목록·배선·펌웨어에 반영
- **제약 검증:** 부품, 핀, 전압, 전류 등의 조건을 규칙 기반 엔진으로 검사
- **기기 연동:** Arduino 컴파일·USB 업로드와 Web Serial 출력 확인
- **수업 흐름:** 팀별 진행 단계, 강사 승인, 도움 요청, CSV 리포트

AI가 생성한 제작안을 전기적 제약 검사와 실물 확인 단계에 연결하는 데 중점을 두었습니다.

`React` `TypeScript` `Node.js` `OpenAI API` `PostgreSQL` `Arduino`

### 07. TQQQ Daily Sim

**같은 초기 자금으로 서로 다른 매수 전략을 비교하는 백테스트.**

과거 가격 데이터를 이용해 TQQQ 적립식 매수와 일괄 매수의 결과를 비교하는 Python 스크립트입니다. 적립식 전략에서는 SGOV에 보관한 자금의 일부를 매일 TQQQ로 이동시키며 자산 변화를 계산했습니다.

- **데이터 준비:** yfinance로 가격 데이터를 불러오고 거래일 기준으로 정리
- **전략 비교:** SGOV 자금 보관·TQQQ 적립식 매수와 TQQQ 일괄 매수 계산
- **결과 계산:** 일별 자산 변화, 최종 자산과 최대 낙폭(MDD) 산출
- **시각화:** 두 전략의 자산 추이를 같은 그래프에서 비교

매수 시점과 자금 배분 방식의 차이를 수치와 그래프로 비교할 수 있도록 구성했습니다.

`Python` `pandas` `NumPy` `yfinance` `Matplotlib`

### 08. Portfolio Web

**프로젝트 기록을 웹에서 읽을 수 있는 포트폴리오.**

Notion에 정리한 프로젝트 콘텐츠를 웹사이트로 연결한 개인 포트폴리오입니다. 프로젝트 목록과 상세 페이지를 구성하고, 한국어·영어 화면과 콘텐츠를 읽기 위한 스타일을 구현했습니다.

- **콘텐츠 연동:** Notion API로 프로젝트 목록과 본문 블록 조회
- **다국어 화면:** 한국어·영어 경로와 언어별 화면 문구
- **본문 렌더링:** Notion 블록을 웹 문서로 변환하고 목록 구조 처리
- **화면 구성:** 반응형 프로젝트 카드, 상세 페이지, 전환 애니메이션

콘텐츠 관리와 웹 화면을 연결하고, 프로젝트를 탐색하는 흐름과 본문 가독성을 다뤘습니다.

`Next.js` `React` `TypeScript` `Tailwind CSS` `Notion API` `Framer Motion`

### 09. AirNote

**iCloud Notes를 데스크톱 작업 공간에 연결하는 앱.**

브라우저 탭에서 사용하는 iCloud Notes를 별도의 투명 창으로 열 수 있도록 만든 데스크톱 앱입니다. Tauri 창 안에 웹 콘텐츠와 React 제어 화면을 구성하고, 단축키와 트레이에서 창을 다시 불러오는 흐름을 구현했습니다.

- **서비스 연결:** 전용 WebView에서 iCloud Notes 열기
- **창 구성:** 투명 배경, 사용자 정의 제목 표시줄과 크기 조절
- **빠른 호출:** 전역 단축키와 트레이 아이콘을 통한 창 표시
- **세션 유지:** 앱 데이터 경로에 WebView 세션 저장

웹 서비스를 데스크톱 창과 운영체제의 단축키·트레이 기능에 연결하는 작업을 다뤘습니다.

`Tauri` `Rust` `React` `TypeScript` `WebView`

### 10. HardWire AI Landing Page

**하드웨어 제작 지원 서비스의 첫 화면을 설계한 랜딩 페이지.**

서비스가 해결하려는 문제와 사용 흐름을 소개하는 랜딩 페이지입니다. 하드웨어 맥락을 AI에 전달한다는 아이디어를 화면 예시와 비교 섹션으로 설명하고, 관심 사용자가 대기자 등록 폼까지 이동하도록 구성했습니다.

- **서비스 소개:** 핵심 메시지와 사용 흐름을 보여 주는 히어로 영역
- **화면 예시:** 대시보드 목업과 기능 소개 섹션
- **비교 구성:** 서비스 사용 전후의 흐름을 설명하는 화면
- **등록 폼:** 모달 입력, 로딩·완료 상태와 애니메이션

제품 아이디어를 이해하기 쉬운 소개 화면과 입력 흐름으로 표현했습니다.

`Next.js` `React` `TypeScript` `Tailwind CSS` `Framer Motion`
